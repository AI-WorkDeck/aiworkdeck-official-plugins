# 语音转文字与朗读（`voice-suite`）

AI WorkDeck 官方语音工作台插件（整合原 `EasyVoice` 语音转文字/文字转语音 与 `MeetingRecording` 本地录音纪要）：

- **语音转文字（ASR）**：支持项目内音视频材料（`.mp3` / `.wav` / `.m4a` / `.mp4`）转写、说话人分离（法官/原告代理人/被告代理人/当事人）与法言法语热词增强
- **文字转语音（TTS）**：支持读取当前打开文书选区或自定义段落，多音色与倍速朗读校对
- **一键生成法律笔录**：转写结果可一键插入当前文书光标处，或发送给 AI 提炼庭审代理词/会谈纪要与待办清单
