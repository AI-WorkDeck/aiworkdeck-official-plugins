# 诉讼可视化（`litigation-visual`）

AI WorkDeck 官方插件：从案件卷宗（判决书、起诉状、合同、流水与证据目录）抽取事实与主体语义地图（`semantic-map.json`），经确定性几何管线生成法庭汇报级可视化图件：

- **案件事实时间轴（`timeline`）**：关键节点、诉讼时效中断、保证期间与违约节点标注
- **当事人与担保法律关系图（`relations`）**：主债权、连带保证、抵押质押、代位追偿关系穿透
- **股权与实际控制人结构图（`equity`）**：多层持股比例、一致行动人与实控路径展示
- **诉讼与执行程序流程图（`flowchart`）**：一审、二审、再审、财产保全与执行异议路径
- **履行与审理对比甘特图（`gantt`）**：合同约定履行期 vs 实际履行期对比

交付物统一落入项目同名文件夹：`.drawio`（可二次编辑源文件）、`.svg`（矢量母版）、`.png`（一键插入当前文书）。
